# Aaditya Mandal — NFC Digital Business Card

A lightweight, mobile-first personal site designed to open from Aaditya's NFC card.

## Files

- `index.html` — page content and links
- `styles.css` — all styling
- `assets/aaditya-mandal.webp` — headshot
- `assets/favicon.svg` — browser icon
- `resume/Aaditya_Mandal_Resume.pdf` — résumé used by View and Download buttons

## Current public URL

This build is configured for:

`https://aadimandall.github.io/`

The GitHub repository for a personal Pages site should therefore be named:

`aadimandall.github.io`

## Publish with GitHub Pages

1. Create a new **public** repository named `aadimandall.github.io`.
2. Upload the contents of this folder to the root of the repository.
3. In the repo, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.
7. Open `https://aadimandall.github.io/` on your phone and test every button.
8. Only after testing, write that exact URL to the NFC card as a **Website / URL** record.

## Editing

Everything is intentionally plain HTML + CSS — no framework, no build process, no subscription, and no external font or JavaScript dependency.

- Change wording or links in `index.html`.
- Change colors, spacing, layout, or responsive behavior in `styles.css`.
- Replace the headshot while keeping the filename `assets/aaditya-mandal.webp`, or change the path in `index.html`.
- Replace the résumé while keeping the filename `resume/Aaditya_Mandal_Resume.pdf`, or update both résumé links in `index.html`.
